How the file is read

  • An empty cell means “leave this alone.” To change only stock, keep just the slug, colour_name, size and stock_quantity columns and delete the rest.
  • To deliberately empty a field — clear a sale price, wipe a description — write CLEAR in the cell.
  • slug says which product a row belongs to and must already exist. Import updates products; it doesn’t create them.
  • A colour_name or size the product doesn’t have yet is added. Sizes themselves must exist under Sizes first.
  • Yes/no columns accept yes/no, true/false or 1/0.
  • collections and fabrics hold several slugs separated by a pipe: bestsellers|new-arrivals.
  • If any row is wrong the whole upload is rejected — you never get half an update.

Stock is added, not replaced

Whatever you put in stock_quantity is added to what's already on hand — so a product sitting at 20, uploaded with 100, ends up at 120. Use a negative to write stock off (-2 for breakage). The current level is shown read-only in stock_on_hand (edits to it are ignored), and the exported file leaves stock_quantity blank so re-uploading it changes nothing.

sizeSize name, e.g. “M”. Must exist under Sizes.

price_overridePrice for this one size only; CLEAR to fall back to base_price.
